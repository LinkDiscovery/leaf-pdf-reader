# 문장 패턴 브라우저 추론 검증 (개발 중)

이 문서는 이전 WebGPU 실험 기록이다. 현재 브랜치의 연결 방식은 [Ollama 안내](ollama-analysis.md)를 따른다. 아래의 브라우저 모델 다운로드와 Worker 설명은 이전 실험에 관한 것이다.

2026-11-16. **결론: 이번 브라우저 추론 조합은 배포 보류.** 자동 문법 분석에 필요한 정확도와 안정성을 확인하지 못했다. 화면·저장 흐름과 실험 코드는 `experiment/sentence-pattern-webgpu` 브랜치에 보존하며 `main` 및 운영 사이트에는 반영하지 않는다.

## 구현과 데이터

- 문장 카드 → 패턴 분석 → 명시적으로 분석 시작. 페이지 방문이나 편집창 열기만으로 모델을 내려받지 않는다.
- 분석은 Web Worker / WebGPU에서 수행한다. 외부 추론 API 및 사용자별 API 키가 없다.
- 패턴 한 줄과 한국어 의미 한 줄을 편집한 후 메모에 넣고 저장한다.
- 기존 `note` 문자열에 저장하므로 기존 Firestore 규칙, 동기화, JSON 백업 형식을 그대로 사용한다. 로그인 상태에서 저장한 문장·분석 메모는 Firebase에 동기화한다.
- 원문 변경·취소·편집창 닫기 시 진행 중 작업을 취소한다. 오래된 결과는 적용하지 않는다. 실패해도 원문과 기존 메모를 보존한다.

## 확인된 내용

검증 기기: Windows / Microsoft Edge / Ryzen 7 3700X / RAM 64GB / RTX 2070 SUPER. 다른 노트북의 성능을 보장하는 수치가 아니다.

- PDF·학습 기록·음성·새 패턴 UI 자동 검사 22개 통과.
- Firebase 에뮬레이터 3개 통과. 두 브라우저에 문장 패턴과 기존 메모가 함께 동기화되는 것 확인. 운영 Google 계정 로그인 검사는 아님.
- Qwen3-4B와 Qwen3.5-4B 4비트 모델을 실제 WebGPU에서 실행. 각 모델 최초 다운로드 약 2.3GB, 이 환경에서 준비 약 90초. 준비 후 짧은 문장 분석 약 2~3초. 최초 셰이더 준비가 포함된 첫 분석은 약 24초 걸린 사례가 있음.
- 빠른 응답 모드에서 잘못된 문법 틀과 의미가 발생했다. 예: `prevent + B + from 동사원형`, `Although + 동사원형`. 각각 동명사와 절이 필요하므로 학습용으로 그대로 제공하기 부적합하다.
- 긴 지시문에서 GPU device-lost 오류를 관찰했다. JSON 형식 검사 통과는 문법 정확성을 보장하지 않는다.
- 추론 모드는 일부 요청이 오래 걸리거나 토큰 한도 내에 최종 답을 만들지 못했다.
- Qwen3.5-9B도 비교했다. 가중치 약 4.8GB를 내려받았지만 실제 추론 단계에서 `DXGI_ERROR_DEVICE_HUNG` / device-lost 오류로 중단되어 품질 평가는 완료하지 못했다. 원인이 GPU 메모리 부족이라고 확정할 수는 없다.
- 실제 앱의 Worker에서도 모델 실행 → 결과 표시 → 기존 메모 보존 → 저장 → 새로고침 복원까지 확인했다. 이 흐름의 정상 작동은 모델의 문법 정확성을 뜻하지 않는다.
- 별도 평가용 8문장은 준비했지만, 후보 모델이 앞선 검사에서 탈락하여 독립 품질 평가는 진행하지 않았다.

## 다음 판단

브라우저에서 실행할 수 있다는 사실과 영어 학습에 충분한 품질이라는 판단을 분리한다. 이번 실패가 모든 브라우저 모델의 실패를 뜻하지는 않는다. 서버 프로그램으로 옮겨도 같은 모델의 문법 오류가 자동으로 해결되지는 않는다.

다음 후보는 Ollama 등 로컬 실행기에서 더 큰 모델을 시험하는 방식이다. 노트북을 항상 켜는 외부 공개 서버가 꼭 필요한 것은 아니다. 같은 컴퓨터에서 사용할 때는 로컬 실행만으로 가능하며, 다른 기기에서 요청할 때에만 서버 기기의 가동과 연결 구성이 필요하다. 먼저 대상 노트북의 RAM·GPU 사양을 확인하고, 같은 문장 및 별도 문장으로 정확도·응답 시간을 다시 검증해야 한다.

현재 개발 UI 사용 순서: 나의 문장 → 패턴 분석 → 직접 입력 또는 실험 분석 → 결과 검토 → 메모에 넣기 → 저장. 자동 결과는 정답으로 취급하지 않는다. 처음 분석 시작을 누르면 약 2.3GB가 브라우저 캐시에 저장된다. 캐시 삭제·브라우저 변경 시 다시 받을 수 있다. 이 파일은 Firebase 저장 용량을 사용하지 않는다.

## 재현용 자료

`npm run dev`로 개발 서버를 실행한 뒤 다른 터미널에서 `node scripts/probe-pattern.mjs`를 실행한다. 실제 수 GB 다운로드와 GPU 사용이 발생한다. 결과는 `test-results/pattern-probe-*.json`에 모델·지시문·출력·시간과 함께 남는다. `--model Qwen3.5-9B-q4f16_1-MLC`, `--suite held-out`, `--thinking` 옵션으로 별도 비교할 수 있다. 모델별 정확도는 출력 내용을 사람이 검토해야 한다.

- `tests/pattern/probe.html`: 개발 서버에서 실제 모델을 시험하는 페이지. 배포 빌드에는 포함되지 않는다.
- `tests/pattern/sentences.json`: 개발 중 비교용 20문장. 프롬프트 조정에 사용했으므로 독립 평가 점수로 주장하지 않는다.
- `tests/pattern/held-out.json`: 별도 평가용 문장. 품질 검토는 패턴 문법, 한국어 의미, 원문 대응, 재사용 가능성을 구분한다.
- 자동 UI 검사는 Worker를 모의 처리한다. 실제 모델의 문법 정확도를 UI 검사 통과로 대체하지 않는다.
