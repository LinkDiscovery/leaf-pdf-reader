읽기부터 복습까지

PDF를 열고, 모르는 표현을 찾고, 내 단어장에 남기세요. 로그인 없이도 이 기기에서 시작할 수 있습니다.

1. PDF 열기 · 읽기

PDF 열기를 누르거나 파일을 끌어놓으세요. 페이지 번호로 이동하고, 너비 맞춤 / 한 페이지로 배율을 바꿀 수 있어요.

2. 단어 · 문장 뜻 찾기

영어 단어를 더블클릭하면 오른쪽에 영어·한국어 뜻이 나옵니다. 단어 옆 🔊 듣기로 발음을 듣고, 다시 누르면 멈춥니다. 문장은 드래그한 뒤 뜻 · 번역을 누르세요. 사전 검색창에 직접 입력해도 됩니다.

3. 단어장 · 문장에 저장

PDF에서 드래그하면 뜨는 형광펜 메뉴의 단어장 추가 / 문장 저장을 누르세요. 원문·출처와 이미 조회한 뜻을 채웁니다. 뜻·예문을 확인하거나 직접 입력한 뒤 저장하세요. 새로 만든 형광펜을 다시 눌러 저장하거나 사전의 저장 버튼을 이용할 수도 있어요.

4. 뜻을 가리고 복습

나의 단어장 / 나의 문장 탭에서 검색·수정·삭제하세요. 단어장 카드의 🔊 듣기로 발음도 확인하세요. 뜻·번역 가리고 복습을 켜고, 기억한 항목은 외웠어요로 표시합니다.

5. 형광펜 · 메모 · 내보내기

문장을 드래그해 색을 고르거나 메모 쓰기를 누르세요. 표시를 클릭하면 수정할 수 있어요. PDF 내보내기로 표시와 메모가 담긴 복사본을 저장합니다.

6. 다른 컴퓨터에서 이어 보기

Google 로그인 후 단어·문장을 저장하세요. 로그인 전에 쌓은 기록은 기기 기록 가져오기로 옮깁니다. 동기화 완료를 확인한 뒤 다른 컴퓨터에서 같은 계정으로 로그인하세요.

어디에 저장되나요?

계정에 동기화: 저장한 단어·문장, 뜻·예문·학습 메모·출처와 복습 상태.

이 브라우저에 저장: PDF 형광펜·메모, 로그인 전 학습 기록. PDF 원본은 업로드하지 않으며 직접 폴더로 관리합니다.

학습 탭의 백업 내보내기 / 가져오기로 단어·문장을 파일로 보관할 수 있어요. 온라인 사전·번역에는 조회한 단어와 문장이 전송됩니다.

글자 크기 · 단축키 · AI 바로가기
  • 화면 글자: 상단에서 기본·크게·아주 크게를 선택합니다. 메뉴·설명·학습 카드에 적용되며 이 브라우저에 기억됩니다.
  • 사전 글자: 사전 위의 A− / A＋로 따로 조절합니다. PDF 자체는 배율로 조절하세요.
  • PDF 확대: PDF 위에서 Ctrl+마우스 휠, Ctrl+＋ / −. Ctrl+0은 너비 맞춤.
  • 사전 폭: PDF와 사전 사이 경계를 드래그합니다. 두 번 누르면 기본 폭으로 돌아옵니다.
  • AI 바로가기: 선택한 문장을 복사하고 Claude·GPT·Gemini를 새 탭으로 엽니다. 열린 AI 창에 직접 붙여 넣어 질문하세요.
  • 클릭 효과: 상단 체크로 클릭 위치의 작은 원을 켜거나 끕니다. 기본 마우스 포인터는 그대로 사용합니다.
